## 3. ما تم تصحيحه في الوثيقة

1. **المصطلحات:** استبدال «طابور» بـ «نظام/إدارة الانتظار» في المتن والفهرس والنتائج.
2. **التقنيات:** الوثيقة تذكر Laravel 8 + Livewire + Bootstrap (Valex) — **لا يوجد Tailwind أو Gates/Policies** (متسق مع المشروع).
3. **أرقام الانتظار:** توثيق صيغة `CARD-003`, `NEUR-003` بدل الرمز العربي «ق».
4. **الفصل الثامن:** إزالة أسطر مكررة/يتيمة قبل §8.1.
